# 当地太阳时：与闪电台网独立的第二条腿（2026-09-11）

结论见上两级 `OPEN-QUESTIONS.md` 第 32 条。

- `land_ocean.txt`：**陆海抵消**。83 个闪电证实 TGF 合起来的 LST 是平的
  （瑞利 p = 0.81），但拆成陆 22 / 海 61 之后，陆地那一半 R = 0.588、峰 19.0 h、
  **p = 0.001**，海洋那一半峰 6.8 h，**峰位差 11.8 h**。同样的事在 190 万个 WWLLN
  落点上做：陆地 A = 0.82、海洋 A = 0.32，混在一起只剩 0.32。
  生成：`scripts/diag_svom_lst_land_ocean.py`。
- `local_time.txt`：两成分拟合（雷暴模板 + 平坦本底）。显著池 f_TGF = 0.58
  [0.50, 0.67]，ΔlnL = 25；本底主导的 fa 0.1–1 给 0.02 [−0.04, 0.09]。
  生成：`scripts/diag_svom_local_time.py`。
- `exposure_control.txt`：**经度–曝光耦合的对照**。LST = UT + 经度/15，两者直接
  耦合，所以本底要按被检验样本的经度三分区 × 陆海共 6 格重新加权再验平坦性：
  原始 χ² = 7.0/7，配平后 0.2–0.6/7，更平。生成：`scripts/diag_svom_lst_exposure_control.py`。

**f 与模板幅度 A 简并**，只有乘积被测到；用混合模板得 0.89、用陆海分开的模板得 0.58。
WWLLN 自己的夜间探测效率偏高会压平模板的午后峰，即 A_used < A_true，
**乘性地把整条区间往上推**，所以 0.58 是上限一侧的估计。
- `by_surface.txt`：**按下垫面分类重拟**（陆地／近岸／远洋，GBM 口径：星下点在陆上
  算陆地，海上离陆 < 300 km 算近岸），模板换成 GBM 的零 WWLLN 选样模板。
  陆地 322 个给 f = 0.84 [0.75, 0.93]、ΔlnL = 36.7；**陆地候选自己的 LST 峰位
  18.9 h 对上 GBM 陆地模板的 18.9 h，p = 4.5e-12**（形状预言，不用拟合）。
  ~~近岸/远洋的模板过不了自己的本底对照（纯本底的 fa 0.1–1 在远洋拟出 −0.23），
  搬不过来，那两类的 f 不可用。~~ **这句已撤回，见下条。**
  生成：`scripts/diag_svom_lst_by_surface.py`。
- `template_crosscheck.txt`：**近岸/远洋到底卡在哪**。三组只变一个量的对照
  （只变模板来源 / 只变分类口径 / 只变本底模型）加一条零假设分布（本底抽同样大小
  的子样本拟剩下的本底，真值恒为 0）。结论：**不是模板问题也不是样本问题，
  是灵敏度不够**——那个 −0.23 只有 1.9σ（按日占用配平的零分布），是 9 格里唯一接近 2σ 的一格；海上模板的
  幅度 A 只有陆地的三分之一，f 的零分布 σ 达 0.23–0.38，实测 f = 0.3–0.6 只有
  1.0–1.7σ。陆地那一条则由两套独立模板夹住：GBM 0.84 [0.75, 0.93]、
  HXMT 单点 0.94 [0.83, 1.04]，两套的 A 偏差方向已知且相反。
  池级纯度按计数加权 0.50 ± 0.13。生成：`scripts/diag_svom_lst_template_crosscheck.py`。

- `null_occupancy_check.txt`：零分布的抽法对照（HXMT 组纠正的）。按天整块抽复制的是
  本底自己的日占用，正确的是照抄被检验样本的每日事件数分布。SVOM 两种抽法差 8–22%，
  每一格的结论都不变。生成：`scripts/diag_svom_lst_template_crosscheck.py` 的零分布部分，两种抽法并排。
- `surface_composition.txt`：**第三条腿**（第 34 条），只用星下点的下垫面类别，
  不碰 LST、不碰模板、不碰台网。含前提检验（83 个闪电证实**不是**无偏的 TGF
  构成端点，两类落在端点之外）、几乎不用假设的下界 f ≥ 0.545 ± 0.030、
  以及本底端点固定、TGF 构成自由的联合拟合（纯本底档给 0.02 [0.00, 0.06]）。
  生成：`scripts/diag_svom_surface_composition.py`。
