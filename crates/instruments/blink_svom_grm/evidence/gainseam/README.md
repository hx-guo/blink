# 两档增益交接处的缺口（2026-09-11）

结论见上两级 `OPEN-QUESTIONS.md` 第 30 条。低增益支在某道戛然而止、高增益支从
下一道开始，中间留 1–5 个计数明显偏低的道，2025 年起其中一道几乎为零。
EBOUNDS 与 CALDB 的响应都不知道这件事。**这是数据产品的缺陷，不是分析问题。**

- `gain_seam.txt`：7 个整点小时、跨 2024-07 到 2026-02，逐道给「实测 / 跨缺口
  插值」与两支的逐道计数。判据不依赖模型：紧挨缺口两侧各 3 道做对数线性插值。
  2025-09-19 的 ch135 实测 93 个计数、期望约 17000。
  生成：`scripts/cluster/svom_gain_seam.py`。
- `seam_per_tgf.csv`：83 个闪电证实 TGF 所在小时的交接道（ch106–113，随时间漂）
  与交接处逐道的相对偏差。生成：`scripts/cluster/svom_seam_per_tgf.py`。

对叠加光子谱的影响：挡掉交接道 ±2/±3 道后 α 只动 0.01。
对搜索无影响。**在 0.6–1.2 MeV 做窄带能谱或找线必须先挡掉。**

## 可以直接对外的说法（写给 SVOM 数据组 / 论文附录）

以下这一节按对外可见的形式写，措辞直述，不含内部简称与比喻，可整段取用。
它是一份**观察报告，不是缺陷认定**——我们不掌握星上增益切换的实现细节，
是否需要处理由数据组判断。

**现象。** GRM 事例有两档增益（`GAIN_TYPE` = 0 与 1），两支共用同一套 EBOUNDS。
两支在某个能道交接：低增益支的计数在某道之后迅速降到零，高增益支从相邻某道开始，
交接处留下 1 到 5 个计数明显低于两侧的能道。2025 年起其中一道的计数接近于零：
2025-09-19 00 时那一小时，ch135 实测 93 个计数，两侧插值给出的期望约 17000。
交接所在的能道随任务时间漂移（2024-07 在 ch107 一带，2026-02 在 ch136 一带），
所以缺口对应的能量位置也随时间移动。**EBOUNDS 与 CALDB 的响应矩阵都没有反映
这件事**，用标准响应做谱折叠时会在这几道上系统性高估模型计数。

**测量办法。** 判据不依赖任何谱模型：跨过缺口、取紧挨两侧各 3 道做对数线性插值，
与实测比。整小时三路探头合计上千万个事例，统计误差可忽略，缺口是 100σ 量级的偏离。
七个小时跨 2024-07 到 2026-02，三路探头分别测都给同一结果。缺失计数占比
（缺口那几道相对插值期望少掉的比例）2024 年为 14% 到 36%，2025 年起为 57% 到 66%。
逐道数据见 `gain_seam.txt`。

**影响范围**（就毫秒量级地球伽马闪搜索与能谱表征而言）：

* 搜索不受影响。缺口只占搜索所用 205 个能道中的 1 到 5 个，信号与本底在这几道上
  同比例减少，信噪比不变。
* 叠加谱的幂律指数几乎不受影响。逐事件挡掉交接道及其 ±2 / ±3 道后，
  拟合出的谱指数只变 0.01，因为那几道只占净计数的约 3%。
* 窄带分析会受影响。在 0.6 到 1.2 MeV 做窄带能谱或搜索谱线，必须先按小时定位
  交接道并挡掉。511 keV 位置在 2024 年为 ch99 到 ch102，与 2024-07 那次的缺口
  只差两三道。

**想请教与建议的三点：**

1. 这是否为已知现象。如果星上或地面流程里已有相应处理或标记，我们希望知道正确用法。
2. 如果尚未处理，建议在数据产品里给出交接道的标识，例如在 EBOUNDS 或附加 HDU 里
   逐时段给出低增益末道与高增益首道，使用者可据此挡道。逐小时给出即可，
   缺口的漂移是慢的。
3. 响应矩阵是否可以反映交接。目前 CALDB 的响应在交接道上给出正常的有效面积。

我们逐小时的测量结果与脚本都可以提供。**另有一条同属响应侧、也建议一并反馈的：
背面入射（载荷系入射角 ≥ 90°）在 42–300 keV 的响应与实测不符**，见
`OPEN-QUESTIONS.md` 第 33 条与 `evidence/systematics/theta_mechanism.txt`。
