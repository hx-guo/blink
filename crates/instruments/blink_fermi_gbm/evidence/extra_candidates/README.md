# 「我们有而已发表目录没有」的那批：约四成是真 TGF

2014 年我们的搜索出 846 个显著候选（fa ≤ 1e-5），其中 611 个对得上已发表的
第二版 GBM TGF 目录，**235 个目录里没有**。这 235 个是什么，用 WWLLN 闪电
关联判的。

数据日期 2026-09-10。脚本 `scripts/cluster/gbm_extras_assoc.py`。

## 方法

2014 年的目录同时给了我们**判据**和**对照组**：目录匹配上的 611 个是已认证的
真 TGF，它们在同一套关联判据下的表现就是"真 TGF 长什么样"的标尺。

偶然水平不靠估算，靠**时间平移对照**：把候选时刻整体移开 ±300 s 再查一遍。
位置不动，闪电活动的地理与季节结构全部保住，只有真实的时间符合被破坏。

关联判据与 `blink_lightning::algorithms::associated` 逐行对应：±5 ms、800 km、
闪电取 15 km 高、按星地距离扣光行时。

## 结果

| 人群 | n | 真时刻关联 | 平移 +300 s | 平移 −300 s |
|---|---:|---:|---:|---:|
| 目录匹配的真 TGF（对照组） | 611 | **203（33.22 %）** | 2（0.33 %） | 3（0.49 %） |
| **我们多出来的显著候选** | **235** | **30（12.77 %）** | 0（0.00 %） | 0（0.00 %） |
| 亚阈随机样 fa 1e-3…1（负对照） | 600 | 2（0.33 %） | 1（0.17 %） | — |

三组平移对照合并给出偶然水平 **6/2292 = 0.262 %**。据此：

| 人群 | 关联 | 偶然期望 | P(≥观测) |
|---|---:|---:|---:|
| 目录匹配真 TGF | 203 | 1.60 | < 1e-300 |
| 多出来的显著 | **30** | **0.62** | < 1e-15 |
| 亚阈随机样 | 2 | 1.57 | 0.47 |

**负对照正好落在偶然水平上**（观测 2、期望 1.57、P = 0.47）——判据没有在
无中生有地造关联。对照组 33.22 % 也与目录自己的 WWLLN 表对得上（2014 年
811 个里 253 个带关联，31.2 %）。

## 结论

**那 235 个里至少约 89 个（38 %）是真 TGF**，是已发表目录漏收的。

估计方法：对照组扣掉偶然后的真实关联率是 33.0 %；多出来那批扣掉偶然后有
29.4 个真关联，按同样的关联率反推 29.4 / 0.330 ≈ 89。

**这是下限**，因为多出来那批更暗（见下），对应的闪电多半也更弱、WWLLN
的探测效率更低，所以它们的真实关联率应当低于对照组的 33 %，反推出来的
真 TGF 数就该更多。

剩下约 146 个未定性——既没有关联，也没有证据说它们不是 TGF（WWLLN 全球
探测效率本来就只有百分之几十）。

## 两组的形态差别

| | 目录匹配（611） | 多出来（235） |
|---|---|---|
| 计数 p10/p50/p90 | 12 / 22 / 46 | 11 / **18** / 31 |
| 最佳格 ms p10/p50/p90 | 0.050 / **0.122** / 0.384 | 0.063 / **0.206** / 0.676 |
| fa 中位 | 2.3e-19 | 1.9e-09 |
| \|纬度\| 中位 | 11.2° | 14.1° |

多出来那批**更暗、更宽、显著性更低**。最佳格中位宽 1.7 倍这一条值得注意：
它与第 15 条未决项对得上——目录里 discovery bin > 1 ms 的那一档我们只有
43.2 % 达显著，说明长而暗的一端两边的判据都吃力。**我们这批多出来的，
看起来正是目录自己的阈值够不着的那个更暗更长的尾巴。**

而且这是**只用 2 路 BGO** 拿到的（2014 年镜像没有 NaI 的逐小时 TTE，
已发表目录用的是全 14 路）。

## 一个实现细节

`peak_time` 里的 `timedelta` 只到微秒，所以峰时刻量化在 1 µs 上。关联窗
±5 ms，1 µs 是它的 2e-4，可以忽略。但要做更紧的时刻比对（例如判断我们和
目录报的是不是同一个峰）就得改成整数纳秒算，见脚本里的注记。

## 复现

```
python3 scripts/cluster/gbm_extras_assoc.py matched_sig_2014b.csv "对照组" 0 300 -300
python3 scripts/cluster/gbm_extras_assoc.py extras_sig_2014b.csv  "多出来" 0 300 -300
python3 scripts/cluster/gbm_extras_assoc.py weak_2014b.csv        "负对照" 0 300
```

集群自带的 python3 只有 SQLite 3.34，而 WWLLN 库用了 STRICT 表（需要 3.37+），
读 schema 就会报 `malformed database schema`。装 `pysqlite3-binary` 即可。
