# GBM 的 TTE 里没有双增益重复计数（实测）

GECAM-C 查出过一个真错：ADC 的两条增益支路各写一行，同一个物理光子变成两个
**时戳完全相同**的事例，搜索当成两个独立事例，泊松独立性破掉。GECAM-C 的量：
同探头同时戳的事例对占原始事例 **6.635 %**，其中 **100 %** 是增益一高一低
（PHA 相同的占 0 %，所以逐行去重抓不到），反标定下来 `fa ≤ 20` 的候选
3385 → 2435，**约 28 % 是它造出来的**。

GBM 有没有同样的问题，用 `scripts/cluster/gbm_dup_probe.py` 量了。量的是
**同一路探头内**相邻事例时戳完全相同的对数——跨探头的同时戳是带电粒子穿整星，
那由 `MAX_SIMULTANEOUS_FRACTION` 管，两件事分开数。

## 结论：没有

| 样本 | 探头 | 事例 | 同探头同时戳对 | 占比 | 其中 PHA 相同 |
|---|---|---:|---:|---:|---:|
| 2019-01-01 00z | 14 路（12 NaI + 2 BGO） | 62,952,788 | 197 | **0.0003 %** | 2（1.0 %） |
| 2014-06-15 00z + 05z | 2 路 BGO | 31,692,435 | 82 | **0.0003 %** | 1（1.2 %） |
| GECAM-C（对照） | 25 路 GRD | — | — | 6.635 % | 0 % |

两年都是 0.0003 %，比 GECAM-C 低约 **2 万倍**。逐路也一致（0.0002–0.0005 %），
没有哪一路突出。

留下的那 197 / 82 对与「两个独立光子偶然落进同一个时戳格子」相符，不带
GECAM 那种一高一低的增益特征（PHA 相同占 1 %，197 对里只有 2 对，是噪声）。
在这个量级上，是偶然符合还是极微量的重复写，对下游没有任何区别。

## 因此

2014 与 2019 的候选计数、完备性、以及 `evidence/train_threshold/` 里的
train 阈定标**都不需要因为重复计数重算**。

两年都查是必要的：2014 只有 2 路 BGO、2019 是 14 路，探头数不同重复的表现
也可能不同——实测两者一致。

## 复现

```
python3 scripts/cluster/gbm_dup_probe.py 2019-01-01 0
python3 scripts/cluster/gbm_dup_probe.py 2014-06-15 0 5
```
