# GECAM-C 候选量爆表的成因与判据检验

数据基础：2023-06-15 一整天，`blink search --instrument gecam-c` 出 **3385 个候选**
（配置的假阳性率是每年 20 个）。以下所有数字都是在 IHEP 集群上对归档事例流直接统计
得到的，脚本见本目录。凡"实测"字样都指这一天的全量候选；样本只有一天的地方，
文中逐条注明。

**对账。** 任何回到事例流重算候选窗内量的脚本，第一步都是把重算计数与搜索报的
`count` 对账。窗口一律取最佳格 `t0 = start + delay`、`t1 = t0 + bin_size_best`，
不用 `[start, stop]`。三个脚本全部 **3385/3385 逐条相等**：
`gc_cpd_norm.py`（CPD 计数与 `feat3.csv` 的 `cpd_*` 列）、`gc_xdet_feat.py`（`n_core`）、
`gc_ebounds.py`（`n_core`）。

## 一、时戳"量化步长"不是仪器参数，是 float64 的 ulp

`TIME` 列是 FITS 的 `D` 型（float64）秒，`TSTART = 7.737e7`。实测：

| 日期 | MET 量级 | 最小正间隔 | = |
|---|---|---|---|
| 2022-08-15 | 5.1e7 s | 7.4505806e−09 s | 2⁻²⁷ |
| 2023-06-15 | 7.7e7 s | 1.49011612e−08 s | 2⁻²⁶ |

把相对时刻除以 2⁻²⁶，余数中位 0、p99 0、最大 0（完全整除）；`np.spacing(TSTART)`
与 2⁻²⁶ 之比为 1.0000。**所谓量化步长就是该量级上 double 的 ulp**，跨过 2ⁿ 秒粗一倍。

对 GECAM-C：MET < 2²⁶ s（**2023-02-19 之前**）步长 7.45 ns，之后 14.9 ns。
对 A/B（历元 2019-01-01）：2²⁷ s 落在 **2023-04-01**，之前 14.9 ns、之后 29.8 ns；
A 星数据绝大多数在 2025 年之后，步长 29.8 ns，是 C 星的两倍粗。

**后果**：任何按偶然撞车期望归一化的同戳判据，其基准常数在三颗星上不同，
并且在任务中途会跳一次。仪器真实时间分辨率 ≤ 7.45 ns，被归档格式抹掉了。
交接材料里的 0.03 µs 是错的。

修正后的锚点：8 个计数、84 µs 窗、q = 14.9 ns 时偶然撞一对的期望是 **0.50%**
（不是 1.0%）；三路同戳的期望 1.8e−6，n=70 / 1 ms 时也只有 1.2e−5。

GECAM-C 时序标定论文（arXiv 2308.11362）给的**探头间相对定时精度是 0.1 µs**
（绝对精度对 Fermi/GBM 为 2.02±2.26 µs）。按这个指标，一个粒子穿两路探头，
两路时戳可以差到 100 ns，所以同戳判据用严格时戳相等偏紧，应当用 ~0.1 µs 容差。
实测两版差别不大（窗内有跨探头同戳的候选：严格 91.3%、100 ns 容差 93.5%）。

## 二、高/低增益双记录：keep 之后仍有 3.25% 的计数被数两遍

实测 2023-06-15 12h、12 路 GRD 全量：同一路探头同一时戳的事例对占原始事例 **6.635%**
（EVENTS01 单路 7.855%）。这些对：

* `GAIN_TYPE` **100% 一高一低**，PI 相同的占 0%（高增益条中位 448 = 溢出道、低增益条中位 377）
* `FLAG` 组合 **100% 是 (0,10) 或 (10,0)**
* `EVT_PAIR` 是 `2X`（每事例 2 位布尔），同戳对两端 **100% 为真**；非同戳事例只有 5.0% 为真

即**同一个物理光子被 ADC 的两条增益支路各写了一行**。多数情况下高增益那条落在
溢出道被 `PI < 448` 挡掉（98.8%），但不是全部：

* `keep`（`EVT_TYPE==1` 且 `54 <= PI < 448`）之后仍有 **1.62% 的事例对**是同一物理事例的两条记录
  → **约 3.25% 的 keep 后计数是重复计数**
* 候选窗内这个比例是 **6.82%（富集 2.1 倍）**；**50.4% 的候选窗含至少一对**

重复的两条时戳完全相同，泊松独立性直接破掉。粗估影响（按候选的 `count` 扣掉
`same_det_extra`、本底率同步降 3.25%，用 (count, mean, fa) 反标定试验数 T ≈ 9.6e9
后重算 fa；**T 的四分位有 ±20% 散布，这是近似**）：

```
fa <= 20    3385 → 2435（剩 72%）
fa <= 1     1707 → 1337（剩 78%）
fa <= 0.01   896 →  732（剩 82%）
```

**约 28% 的候选是双增益重复计数造出来的。**

**顺带解决 OPEN-QUESTIONS 第 4 条**：`FLAG` 不是独立的溢出标志，它标的是双增益对里的
角色（同戳对里恒为 (0,10)/(10,0)）。"FLAG=10 的 PI 中位是 448"是这件事的表象。

## 三、同戳判据（`multiplet_frac`）：有效、不充分、且对亮暴原理上失效

### 3.1 方法自检先过

"候选窗内 CPD 超出 = 带电粒子"这条推理的前提是 CPD 与 GRD 同时基、无共同读出假象。
两个零假设对照，用与正式统计完全相同的机器（当地实测 CPD 率 × GTI 有效时长）：

| 对照 | ±10 µs | ±100 µs | ±1 ms | ±10 ms |
|---|---|---|---|---|
| 平移（每个候选窗整体挪 ±0.2/±0.5 s，13540 次） | 1.008 | 1.004 | 0.987 | 1.005 |
| 随机（GTI 内均匀抽时刻，窗长从候选分布抽，13540 次） | 1.009 | 1.002 | 1.001 | 1.003 |

全部 |z| ≤ 1.4。**期望值算法无偏，CPD/GRD 无共同假象。**

### 3.2 判据确实在挑光子（每个窗长箱一致）

裸的"CPD 命中率"不能比：幸存者的窗系统性更长（中位 169.8 µs vs 全样本 85.2 µs）。
归一化成 **观测/期望**（期望 = 当地实测 CPD 率 × 符合窗的 GTI 有效时长）后：

```
窗长箱(µs)   ±10 µs obs/exp  幸存 / 被切        z
<10          1.37 / 16.08                   −7.18
10–50        2.58 / 12.08                   −4.51
50–200       3.13 /  8.84                   −6.29
200–1000     1.83 /  3.35                   −2.95
合计         1.90 /  8.40                  −14.89
```

±100 µs 同样四箱全负。**没有一个窗长箱是反的。** 判据把 CPD 可见的紧符合粒子签名
压掉约 **4.4 倍**，残留粒子份额上限 **≤12%**（±10 µs 口径）/ ≤30%（±100 µs）。

曾经被当成反证的两条都是窗长混杂：

* "200–1000 µs 箱里幸存者 CPD 命中率 32.3% > 被切者 14.8%"——箱内幸存者窗长中位
  555.1 µs、被切者 312.1 µs（差 1.8 倍）。归一化后 1.83 vs 3.35。把这一箱再对半切，
  两半都保持负号（z = −1.64 / −2.24）。
* "fa≤0.01 的 25 个幸存者命中 9 个、期望 0.6，15 倍超出"——期望用中位窗长（55 µs）
  × 全局 330 c/s 算的。这 25 个里有 6 个窗长约 1 ms 且当地 CPD 率 2857–3371 c/s，
  正规期望是 **6.25**（exp 中位 0.015、均值 0.756，中位数在这里没有代表性）。
  正规结果 **9 / 6.25 = 1.4×**。

### 3.3 但判据不充分

排除高粒子环境（CPD 本底率 > 500 c/s，占幸存者 14%、全样本 4.1%）之后，幸存者的
±10 µs 超出反而升到 2.92±0.42；`fa ≤ 0.01` 的 18 个低本底幸存者里 3 个在 ±10 µs 内
有 CPD 计数、期望 0.23，**P(≥3 | 0.23) ≈ 0.2%**。样本只有 3 个事例，但方向明确：
**显著端仍有约 15–20% 的残留粒子。**

### 3.4 对亮而长的粒子暴：原理上失效

`mf ≤ 0.3` 的通过率随窗内计数单调上升（已做 1 s episode 去重，代表候选）：

```
计数  8–10   n=2444  通过  9.2%   窗长中位  66.7 µs  点亮 6 路   硬度比 1.67
计数 10–15   n= 550  通过 30.0%   窗长中位 209.3 µs  点亮 7 路
计数 15–30   n= 111  通过 53.2%   窗长中位 711.6 µs  点亮 8 路
计数 >=60    n=   5  通过 100%    窗长中位 978.6 µs  点亮 12 路
```

但根因不是分母。9 个亮暴（去重后 count ≥ 30）逐条：

```
start                    count  bin_us  ndet  max_d     mf   xdet   pi_r  cpd10
2023-06-15T14:08:38.123    108   990.1    12      1  0.111  0.000  1.12      7
2023-06-15T14:08:35.068     88   997.8    12      1  0.091  0.000  1.13     10
2023-06-15T14:08:59.621     81   962.6    12      1  0.148  0.000  1.20      5
2023-06-15T22:51:19.344     67   978.6    12      1  0.030  0.000  0.93      3
2023-06-15T22:51:04.186     62   963.2    11      1  0.000  0.000  1.07      2
2023-06-15T14:08:36.156     59   402.5    12      1  0.034  0.000  1.00      3
2023-06-15T14:09:00.740     57   710.2    11      2  0.105  0.035  1.31      1
2023-06-15T14:08:28.840     45   775.2    11      1  0.000  0.000  1.01      2
2023-06-15T22:50:58.429     35   719.3    10      1  0.057  0.000  0.95      1
```

`max_d` 是同戳簇里的最大探头数，`xdet` 是跨探头同戳占比。**9 个里 8 个 `max_d = 1`、
`xdet = 0.000`——窗内一对跨探头同戳都没有。**它们那点 `mf`（0.03–0.15）全部来自
同探头的双增益重复，不是粒子签名。

物理上说得通：单个粒子穿整台仪器才会在同一时戳点亮多路；**簇射是几十个粒子在 1 ms
里陆续到达，各有各的时戳**。因此：

> **任何基于"同戳"的判据——不管用占比还是绝对数、不管跨探头还是同探头——原理上
> 就抓不到亮而长的粒子暴。换分母救不了。**

实测佐证：对 45 个 `count ≥ 30` 的候选，`mf ≤ 0.3` 放行 45/45，`max_d ≤ 2` 放行 45/45，
`max_d ≤ 1` 放行 37/45。能抓住它们的只有 CPD：9 个全部 `cpd10 ≥ 1`，CPD 本底率中位
2557 c/s，硬度比 ≈ 本底。

### 3.5 跨探头 / 同探头拆分：救不回来

`xdet_frac`（只算跨探头同戳）与 `same_det_extra`（同探头多余事例）拆开后逐一试：

```
判据                        幸存数  ±10µs obs/exp  低本底子集  fa<=0.01 命中/期望
multiplet_frac<=0.3          528      1.90          2.92      3 / 0.23  (13.3×)
xdet_frac<=0.3               923      2.00          3.19      4 / 0.43  ( 9.3×)
xdet_frac==0（一对都没有）     293      1.80          2.43      1 / 0.09  (10.8×)
xdet_frac_tol(100ns)==0      219      1.93          1.90      0 / 0.05
```

跨探头版本没有更干净（同样阈值下幸存者多一倍而 obs/exp 更高）。**残留不是定义粗
造成的，不必改 `multiplet_frac` 的定义。**

## 四、列车密度（`neighbors_10min`）在 GECAM-C 上双向失效

一天 3385 个候选，±600 s 内的邻居数：中位 53、均值 54.0、四分位 45–63、5–95% 31–75、
最大 97。均匀分布下的期望 = 池率 × 1200 s = 47.0。

* **绝对阈 34 坐在分布的第 8 百分位** → 摘掉 92.2%，把 `fa ≤ 0.01` 的干净幸存者
  15 个摘掉 15 个（100%）。
* **按池中位缩放 `max(34, round(3.78 × 53)) = 200`，高过分布最大值 97 → 摘掉 0 个。**

对检验样本零分辨力：14:08 那串 36 个候选（0.63 s 内）邻居数 61，22:51 那串 17 个
邻居数 83–85，都在池中位水平——**一次亚秒的粒子增强在 ±600 s 的计数窗里看不见**。

邻居数在编码什么：

```
邻居  9–45  n=878  mf<=0.3 15.6%  CPD命中 12.6%  CPD率 136  |lat| 中位 70.7°
邻居 45–53  n=924          13.6%          14.0%        132        40.3°
邻居 53–63  n=958          15.7%          15.4%        111        33.3°
邻居 63–72  n=600          13.2%          13.0%         90        21.0°
邻居 72–97  n=360          21.1%          14.7%         85        14.8°
```

真伪相关的量在五档之间是平的，唯一强相关的是**地理纬度**。**在 GECAM-C 上
`neighbors_10min` 携带的是轨道位置信息，不是真伪信息。** GECAM-C 需要的是亚秒尺度的
成串判据，不是 10 分钟尺度的。

## 五、与已发表 GECAM TGF 目录的对比（OPEN-QUESTIONS 第 10 条）

**样本身份。** Zhao et al. 2023, GRL, `10.1029/2022GL102325`（arXiv 2306.10255）：
**147 个 TGF，只用 GECAM-B**（原文："only GECAM-B data are utilized here because
GECAM-A has not been able to observe yet"），**2020-12-10 至 2022-08-31**，有效观测
274.5 天。判据是"≥2 个 GRD 组各 ≥8 计数、100 µs 分箱"，P 值严到 2e-21——是亮事件搜索。

**目录本体是公开的**：Zenodo `10.5281/zenodo.8028217` 里的 `GECAM_TGF_Catalog.xls`，
147 行，列为 `UT`（µs 精度）、卫星经纬高、`Duration_us`（Bayesian Block）、`NetCounts`、
`HardnessRatio_200keV`、`CPDtoGRDcountsRatio`。

### 5.1 对 GECAM-C 的直接完备性检验：做不了

C 星 2022-07-27 入轨，与目录时间段只重叠 4 个事件。逐个查 C 星当时的位置与数据：

```
2022-07-30T19:47:13  GECAM-C 该小时无 POSATT 文件
2022-08-07T01:54:38  GECAM-C 该小时无 POSATT 文件
2022-08-07T13:18:08  GECAM-C 该小时无 POSATT 文件
2022-08-30T11:53:55  GECAM-C 星下点 (154.978, 29.653)，与 B 星下点相距 13047 km
```

**可用重叠为零。**（TGF 地面足迹半径约 800 km，13047 km 是地球另一侧。）
这条检验对 **GECAM-B** 才成立，是 147 个事件对 2020-12..2022-08 的直接完备性检验。

### 5.2 但目录的定标价值很大

```
Duration_us            中位 179.5   5–95% 35.7–372    最大 670.9   → 100% < 1 ms
NetCounts              中位  66.9   5–95% 21.2–185    最小   8.7   → 只有 3.4% < 20
HardnessRatio_200keV   中位 0.679   四分位 0.588–0.786
CPDtoGRDcountsRatio    中位 0.040   5–95% −0.010–0.178   34.7% <= 0
|纬度|                 中位 11.5°   >30° 占 0.0%
```

（`|纬度| < 30°` 是 GECAM-B 轨道倾角 29° 的限制，不是 TGF 的物理性质，
**不能用来判 C 星候选的纬度分布**。C 星在太阳同步轨道，覆盖全纬度。）

1. **窗长上限 1 ms 是对的（第 7 条可以关）**：147 个真 TGF 100% 短于 1 ms，
   中位 179 µs、95% 分位 372 µs。我们幸存者的窗长中位 169.8 µs 与之相符。
2. **`min_number = 8` 已探到真样本分布的最底边（第 6 条）**：真 TGF 只有 3.4% 少于
   20 计数、最暗一个 8.7 计数。我们的候选计数中位 10、只有 10.4% ≥ 21——阈值比
   已发表样本低整整一档。
3. **CPD 不能当零容忍判据（第 2 条）**：真 TGF 的 CPD/GRD 比中位就是 **0.040** 而非 0
   （CPD 是塑料闪烁体，对伽马有康普顿响应；TEB 的比值才高得多）。按 B 星 8 路 CPD /
   25 路 GRD 折到 C 星 2 路 / 12 路，比值约 0.021，一个 8 计数的真 TGF 期望 CPD 计数
   0.17、P(≥1) ≈ 15%。**"±10 µs 内无 CPD 计数"这条否决会误杀约 15% 的真 TGF。**
   原文给的 TGF/TEB 分界线是 `y = −0.39·log₁₀(x) + 1.42`（x = 时长 µs，y = CPD/GRD 比）。
4. **速率锚点**：GECAM-B 在 274.5 天里 147 个 = **0.54 个/天**，且轨道只覆盖 TGF 主产区。
   C 星 12 路 GRD（B 的一半面积）、太阳同步轨道（在热带的时间占比更低），即使阈值
   低一档，量级也就是每天零点几到几个。**我们切完剩几百个/天，仍高 2–3 个量级。**

## 六、`pi_ratio` 是错的尺子，候选并不软

`pi_ratio` 是**道号之比**，而 GECAM 的能量梯是对数的（每道约 1.34%），所以道号比
严重压缩了真实的能谱差异，也不能跨仪器比较。用真实 EBOUNDS 换算（ch150 = 198.9–201.2 keV）：

```
pi_ratio 1.0–1.1 (n= 215) → 能量比中位 1.09，窗内中位能量 156 keV
pi_ratio 1.2–1.3 (n= 531) → 能量比中位 1.48，窗内中位能量 210 keV
pi_ratio 1.4–1.5 (n= 526) → 能量比中位 1.95，窗内中位能量 270 keV
pi_ratio 1.8–2.5 (n= 224) → 能量比中位 4.24，窗内中位能量 558 keV
```

**交接材料里"幸存者谱比中位 1.27，跟天格短硬暴的 3.0 差得远"是两把不同的尺子。**

按已发表目录的同口径（200 keV 分界的硬度比）重算：

```
样本                        n     中位能量   >200keV占比   硬度比
本底（窗外 ±1 s）                    139 keV     0.391       0.643
全部候选                   3385     239 keV     0.625       1.667
mf<=0.3 幸存                528     211 keV     0.500       1.000
幸存 + CPD 双否决            405     217 keV     0.545       1.167
幸存 + 双否决 + fa<=1         89     230 keV     0.600       1.450
被切 mf>0.3                2857     245 keV     0.625       1.667
亚微秒窗候选                 366     266 keV     0.646       1.667
天格 B 角同型（亮）            42     163 keV     0.417       0.715
```

已发表 147 个 TGF 的 `HardnessRatio_200keV` 中位是 0.679。**干净幸存者里 73% 的硬度比
≥ 这个值。候选不软。**

两点保留：(a) 原文没有给出硬度比的数学定义（只说"energy limitation 200 keV"），
若它其实是"200 keV 以上的计数占比"而非"以上/以下之比"，则真 TGF 是 0.679 = 68%
而我们幸存者是 50–55%，方向相反——**这个歧义没有解决**；(b) GECAM-C 的**本底本身**
硬度比就有 0.643，与已发表 TGF 中位 0.679 几乎相同，所以在 C 星上硬度比本身分辨力有限
（C 星在太阳同步轨道，本底粒子成分比 B 星 29° 轨道硬得多）。

## 七、天格（GRID）B 角形态在 GECAM-C 上的对照

天格给出 40 个"B 角"候选：谱硬度中位 1.00（自举 95% 上限 1.25）、T90 中位 2963 µs、
|偶极磁纬| 中位 45.9°、闪电关联 0/40、4 路探头全亮且单路占比 0.33。他们没有 CPD，
分不开"弥散的粒子沉降"和"各向同性的光子"，也无法排除是慢读出星特有的伪信号。

在 GECAM-C 这一天的候选里按同样形态筛（窗长顶到 1 ms 上限 + |偶极磁纬| ≥ 33° +
谱比 < 1.15）：**22 个候选 → 7 个独立 episode**（10 s 间隔聚簇，其中 5 个是孤立单个）。
放宽成"谱比 < 1.15 且 |磁纬| ≥ 33° 且 计数 ≥ 20"：**42 个候选 → 8 个 episode**。

```
                 天格 B 角(n=30)            GECAM-C 同型(8 episode)
窗内计数          中位 53（5–95% 18–82）     中位 66
时标             T90 中位 2915 µs           顶到 1 ms 搜索上限（被截断）
谱               硬度 1.00（上限 1.25）      硬度比 0.715，中位能量 163 keV（本底 139）
探头             4/4 全亮，单路占 0.33       12/12 全亮
|偶极磁纬|        中位 45.9°                 中位 76.9°
闪电             0/40                       待测
CPD              无 CPD                     **±10 µs 命中 93–100%**
环境             —                          CPD 本底率中位 2884 c/s（全样本中位 125）
```

**这批是带电粒子沉降，不是光子。**

**边界条件**：把亮度条件去掉（只要谱比 < 1.15 且 |磁纬| ≥ 33），得到 350 个候选 /
271 个 episode，CPD ±10 µs 命中率只有 20%（全样本 14%），在低本底环境里掉到 10%
——**暗端的同型形态 CPD 分不开**。所以结论限定为：**计数 ≳ 20 的那一支确证是粒子；
暗端 CPD 给不出判决。** 天格 B 角的计数中位 53、5% 分位 18，落在能判的那一支里。

两条附带线索给天格：(a) T90 ≈ 3 ms 的东西在 1 ms 搜索窗上限下会被截成"顶到上限"的
候选，这是一条不依赖 CPD 的判别线索；(b) GECAM-C 的读出与天格无关，同形态照样出现,
**所以这个形态不是天格的读出假象**。

**样本量的老实话**：8 个 episode，全在同一天。
