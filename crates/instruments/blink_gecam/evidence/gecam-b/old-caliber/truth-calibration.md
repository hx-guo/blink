# GECAM-B 真值定标：147 个已发表 TGF 当正样本（2026-09-11，**旧口径**）

## 口径声明（先读这一段，否则下面的数会被误用）

**候选池是 `e34f560` 那版二进制跑出来的 300.8 万个候选**，双增益去重只按
「同探头时戳完全相等」合并。统筹后来实测这条规则在 GECAM-B 上只覆盖真实重复的
**88.44%**，漏掉的 11.56% 落在 **89 / 104 ns** 上——正好是候选窗的尺度。所以：

* 本文所有**依赖窗内 GRD 计数**的数（`multiplet_frac`、`f₃`、窗内计数 `n`、
  `bin_size_best` 的分布）都是**旧口径**，等新口径重跑完要复算一遍。
* **不依赖 GRD 去重的数不受影响**，本文里有两处：
  * **CPD 与 GRD 的时戳差**（第五节）——CPD 表没有 `GAIN_TYPE`，不参与双增益
    去重；受影响的只有「多一点没并掉的 GRD 时戳会略抬偶然同戳率」这个二阶项。
  * **逐路基线零格**（第六节）——基线窗是 2 s 尺度，89 ns 的漏并改不了零不零。

**两套数并排放着是有用的**：重跑完复算一遍，差多少就是「双增益判据从时戳相等
换成死时间」这一步的定量效果。

**窗口取法（统筹问到的那条，明确回答）**：本文所有 TGF 侧的量，窗口是
**我们匹配上的候选自己的最佳格** `t0 = start + delay`、`t1 = t0 + bin_size_best`，
**不是「目录 UT + Duration_us」**。对账 `n_core != count` 的 **0 / 140**，
逐条相等。所以第四节那个 `CPD ±10 µs obs/exp = 7.50` **不是本底窗的数**。
反过来，第三节里我确实另外量过「目录 UT + Duration」那个窗，量出来的结果
独立证实了目录 UT 系统性偏早——见第三节。

数据与脚本：集群 `/scratchfs2/gecam/guohx/gecambrun/`，脚本副本在同目录
`scripts/` 下。

## 零、这批真值能证明什么、不能证明什么

147 个来自 Zhao et al. 2023 GRL（arXiv 2306.10255），**只用 GECAM-B**，
2020-12-10 至 2022-08-31、有效观测 274.5 天，判据「≥2 个 GRD 组各 ≥8 计数、
100 µs 分箱」、P < 2e-21，`Duration_us` 是 Bayesian Block 块长。

**这是触发式亮样本**：`NetCounts` 中位 66.9，而我们候选的计数中位是 **9**。
所以下面每一条「判据不切真 TGF」的结论都只在**亮端**成立，**证明不了暗端**，
而暗端正是绝大多数候选所在的地方。凡是按亮度分档能看出趋势的，本文都分了档
（第二、三节），趋势一律是**越暗越危险**。

## 一、完备性与匹配的偶然余量

沿用上一轮的 **142/147 = 96.6% 找回、142/142 全部 `fa ≤ 1e-5`**；逐事件特征
表 140 行（2 个重算窗内计数为 0 被跳过）。搜索的 138 个小时全部 searched，
曝光 346,934 s = 4.02 天，候选 3,008,278 个。

**匹配容差的余量以前没算过，补上。** 匹配规则是「±10 ms 内取最显著的一个」。
候选率 3,008,278 / 346,934 s = **8.67 个/s**，所以 ±10 ms 窗里偶然撞上别的
候选的期望是 **0.173 个/TGF**，142 个匹配里理论上可以有 **约 25 个**是偶然。

**实测没有发生**：`|dt|`（我们的最佳格起点 − 目录 UT）中位 0.107 ms、
75% 0.407、95% 1.82、**最大只有 3.06 ms**，`> 2 ms` 的只占 4.3%，**没有铺满
±10 ms**。偶然匹配若真的发生，`|dt|` 会在 3–10 ms 上有一条平底，实测那一段
是空的。**结论：±10 ms 这个容差在 B 星上是安全的，但它的安全余量来自实测的
`|dt|` 分布，不是来自容差本身——别在别的星上照抄这个数。**

## 二、`bin_size_best`：真 TGF 与候选池是两个人群

同一台仪器、同一套搜索、同一段时间，两个人群在最佳格宽上的分布：

| | 中位 | < 1 µs | < 10 µs | < 50 µs |
|---|---|---|---|---|
| 140 个真 TGF | **111.4 µs** | 2.1% | 6.4% | 17.9% |
| 300.8 万候选池 | **0.134 µs** | **75.9%** | 84.1% | 98.0% |

（池的分位数由 1/97 抽样的 31,008 个算出；独立地，整池按格宽分档的计数给
`bin < 1 µs` 占 2,297,476 / 3,008,278 = 76.4%，两个数自洽。）

真 TGF 的 `bin_size_best` 分位：5% 2.5、25% 64.4、中位 111.4、75% 171.5、
95% 295.8、最小 0.104、最大 990.1 µs。**100% 短于 1 ms**，与目录
`Duration_us`（BB 块长）中位 176.4 的量级一致，`bin_best / Duration_us`
中位 **0.81**。

切一刀的代价与收益（真 TGF 存活带 Wilson 95% 区间）：

| 阈 | 真 TGF 存活 | 池存活 | 池剩下 | 净富集 |
|---|---|---|---|---|
| `bin ≥ 1 µs` | 97.9% [93.9, 99.3] | 24.1% | 72.5 万 | 4.1× |
| `bin ≥ 10 µs` | 93.6% [88.2, 96.6] | 15.9% | 47.8 万 | 5.9× |
| `bin ≥ 50 µs` | 82.1% [75.0, 87.6] | **2.0%** | 6.0 万 | **41×** |
| `bin ≥ 100 µs` | 52.9% [44.6, 60.9] | 0.8% | 2.4 万 | 66× |

**这与 OPEN-QUESTIONS 第 14 条「最小窗长判据——白搭，不要动 `min_duration`」
方向相反，而那条是在 GECAM-C 上得的。** 两星的池结构本来就不同：C 星亚微秒
候选只占 10.8%，**B 星占 75.9%**。B 星 25 路、能阈过滤前约 22 kc/s，亚微秒
同戳堆积比 C 星多一个数量级。**C 星那条结论不必推翻，但它不是通则。**

**给 A 星的一条直接用得上的话**：A 星候选 `bin_us` 中位 0.15 µs，与 B 星池的
0.134 µs 几乎一样，而真 TGF 在 111 µs——**A 星那整个池在这个量上与真 TGF 是
两个人群**。

按最佳格量（140 个）：

**`mf ≤ 0.3` 切掉 12 个已发表 TGF = 8.6% [5.0, 14.4]。**

**这不是我们最佳格选错造成的假象——用构造无关的量复测过。** 复测办法：

## 四、CPD 判据：`±10 µs 内有 CPD 计数` 这条路子被真值证伪

140 个真 TGF，窗口是各自的最佳格，期望按各自的当地 CPD 环境率
（候选两侧各 1 s 的 CPD 计数 / 2 s）逐候选算 `μ = r·(bin + 2·half)`、
求 `Σ(1−e^−μ)`：

| 口径 | 命中 | 偶然期望 | **obs/exp** |
|---|---|---|---|
| ±10 µs | 101/140 = 72.1% [64.2, 78.9] | 9.6% | **7.50** |
| ±100 µs | 103/140 = 73.6% [65.7, 80.2] | 19.7% | 3.73 |
| ±1 ms | 118/140 = 84.3% [77.4, 89.4] | 71.5% | 1.18 |
| ±10 ms | 139/140 = 99.3% [96.1, 99.9] | 99.3% | 1.00 |

**真 TGF 自己就有 7.5 倍的 CPD 紧符合超出。** 物理上说得通：CPD 是塑料
闪烁体，对 TGF 的伽马有康普顿响应。这不是我们的推断，**已发表目录自己带的
`CPDtoGRDcountsRatio` 中位 0.040 就是目录作者测的同一件事**，而且那个数与
我们的窗口取法无关。我们按最佳格重算的净比值 **0.048**，与目录的 0.044 对得上。

**对照**：OPEN-QUESTIONS 第 14 条里 C 星「被 `multiplet_frac` 切掉的那批」
obs/exp 是 **8.40**——**与真 TGF 同一水平**。所以「±10 µs 内有 CPD 计数 ⇒
带电粒子」这条判据在这个口径上没有分辨力。

**代价**：拿它否决要误杀 **72.1%** 的已发表 TGF。要求「窗内无 CPD 计数」
更狠——真 TGF 只有 **18.6% [13.0, 25.8]** 满足。

**同一件事的第二条**：C 星那条配套判据「CPD 本底环境率 ≤ 500 c/s」
**直接搬到 B 星会否决 69.3% [61.2, 76.3] 的真 TGF**。根因是量纲：阈是绝对
计数率，而 B 星 8 路 CPD、C 星 2 路。

| 阈（总率） | 折合每路 | 被否决的真 TGF |
|---|---|---|
| 500 c/s（C 星那条原样搬） | 62 | 69.3% |
| 1000 c/s | 125 | 17.1% |
| 2000 c/s | 250（= C 星的每路阈） | **0.7%** |

B 星真 TGF 处的 CPD 环境率中位 610 c/s（每路 76），候选池中位 692 c/s。
**跨星搬 CPD 阈必须按路数折算，这与口径新旧无关，是量纲问题。**

## 五、CPD 判据该换成什么：**同戳**，不是「窗内有没有」

物理上该分开的是两件事：

* **一次带电粒子穿过整台仪器**：CPD 与多路 GRD 在**同一个时戳**上各留一个
  计数——是同一次沉积。
* **TGF**：CPD 里那个计数是**另一个**伽马光子康普顿散射来的，与任何一个 GRD
  计数**没有理由同戳**，只是同处在几十微秒的暴发里。

所以判别量应该是 `min |t_CPD − t_GRD|`，亚微秒分辨。实测（正样本 = 145 个
目录 TGF 的构造无关峰窗，对照 = 同小时随机抽的 40,800 个池候选的最佳格；
两侧各外扩 100 µs 取 CPD）：

| | 真 TGF | 对照候选 |
|---|---|---|
| 候选数 | 145 | 40,800 |
| 窗内 CPD 计数 | 363 | 30,342 |
| `\|Δt\|` 中位 | **0.268 µs** | **0.000 µs** |
| `\|Δt\| == 0`（同戳）的 CPD 计数占 | **5.79%** | **62.04%** |
| `\|Δt\| ≤ 0.05 µs` 的占 | 16.80% | 71.88% |
| `\|Δt\| ≤ 0.1 µs` 的占 | 26.17% | 72.87% |
| `\|Δt\| ≤ 1 µs` 的占 | 81.54% | 75.26% |
| 有 ≥1 对同戳的候选占 | **11.72% [7.45, 17.97]** | **35.34% [34.88, 35.80]** |

**在 CPD 计数这一级上分离是 10.7 倍**（5.79% vs 62.04%），而原来那个
「窗内有没有 CPD」口径上真 TGF 反而更高。注意 `|Δt| ≤ 1 µs` 这一档两边几乎
相等（81.5% vs 75.3%）——**分辨力全部集中在 0 到 0.1 µs 这一段，窗开到微秒
就没了**。这是本轮最有用的一条：判别量换一个定义，同一批 CPD 数据从没有
分辨力变成有分辨力。

**但它还不够当一条否决判据用**：按候选级「有 ≥1 对同戳就否决」，切掉真 TGF
**11.72%**、切掉池 35.34%，净富集只有 **3.0×**，而且 11.72% 已经违反
「不切任何真 TGF」。**该用的是占比而不是有无**，阈要在新口径的池上重扫。
真 TGF 那 5.79% 里有多少是偶然（TGF 峰内 GRD 密度约 0.5 个/µs、时戳量化
约 0.03 µs，偶然同戳率量级 1.6%）还没算干净，**这一条我标为「方向确定、
阈值未定」**。
