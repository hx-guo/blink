# GECAM-A 的能标实际偏到哪：用 ¹³⁸La 1470 keV 内禀线量

2026-09-10 实测。脚本 `/scratchfs2/gecam/guohx/gecam_a/la138.py`，
逐路原始数据 `la138_peaks.json`。

## 为什么能这么量

LaBr₃ 里的 ¹³⁸La 是内禀放射性，1470 keV 那条线一直都在、强度不随时间变
（CALDB readme 自己说「从2021年11月开始，只使用1470keV一个峰来计算增益，
因为37.4keV消失了」）。所以：**如果 LEVEL1 的 `PI` 是用当期在轨 EC 算出来的，
这条线年年落在同一道；某段若用的是默认 EC 而真实增益已漂，峰位就会系统性移位。**
这个检验不依赖任何标定文档，也不过搜索加载器。

1470 keV 在 448 道梯子上落 **ch303**（1467.7–1487.3 keV）。

**只有低增益档（`GAIN_TYPE == 1`）量得到。** 7 个 epoch 的高增益档全部无峰——
1470 keV 在高增益档已出量程。下表全是低增益档。

## 一、方向：PI 被低估，能阈实际切得更高——是安全的那一侧

峰位偏低意味着真实 1470 keV 的事例被算到了名义 1225 keV 的道上，
即**名义能量低估真实能量**。所以 `PI >= 54` 实际 admit 的是比 40 keV 更高的事例：
**少收信号，不是多收本底。** 候选统计不会因此被污染。

**绝对偏移不可信，只能用相对差。** 即使 2026 有 EC 的那天也比 ch303 低 5 道——
那是重心法的固有偏置（不对称峰坐在陡峭的康普顿台阶上，线性扣本底会把重心往低道拉）。
所以只用相对有 EC 段的差，每道 1.34%，能量比 = 1.0134^Δch：

| 对比 | Δch | 能量比 |
|---|---|---|
| 2022-10-21 vs 2026-06-01 | 11.76 | +16.9% |
| 2023-06-16 vs 2026-06-01 | 6.53 | +9.1% |
| 2024-01-11 vs 2026-06-01 | 8.51 | +12.0% |
| 2024-09-06 vs 2026-06-01 | 7.06 | +9.9% |
| 2024-12-31 vs 2026-06-01 | 8.61 | +12.1% |

**2022-2024 段 PI 低估 9–17%，中位约 12%。ch54 名义 39.1–40.2 keV，
实际能阈落在 44–47 keV。**

## 二、逐路离散：在轨 EC 修的是离群探头，不是整体

MAD 各 epoch 都在 2.2–4.4 ch，差别不大——**核心那批探头本来就挤得很紧**。
在轨 EC 真正改善的是极差：无 EC 段 28–58 ch（能量比 1.5–2.2 倍），
2026 有 EC 后收到 14.4 ch（1.21 倍）。

具体是哪几路（逐路数值见 `la138_peaks.json`）：

* **d15 和 d25 在所有无 EC 的 epoch 里都系统性偏高**——322 / 322 / 319 / 314，
  而大队在 285–295。2026 有 EC 后被拉回队里（293 / 297）。
* **d07 / d08 / d11** 低增益档事例太少，峰面积近零，多数 epoch 量不出峰。
* d10 / d12 / d16 / d17 时高时低，与统计量相关。

**这条对方向分析的含义比中位偏移更重要。** 2022-2024 段不只是整体能阈偏到 44–47 keV，
**逐路的有效能阈还差到 2 倍**。OPEN-QUESTIONS 第 13 条第一档（用逐路计数的相对高低
判"哪边是地球"）若在 2022-2024 段上做，这个逐路能阈不齐会直接伪装成方向信号：
**d15/d25 会系统性地少收事例，看起来就像那两个方向一直是暗的。**
第一档要用 A 星的 WWLLN 段，必须先按这张表把逐路能阈拉平，否则出来的是标定伪影。

## 三、溢出段占比与标定无关

| 日期 | `PI >= 448` | `EVT_TYPE == 2` |
|---|---|---|
| 2022-10-21 | 0.56% | 0.56% |
| 2023-06-16 | 14.12% | 14.12% |
| 2024-01-11 | 13.80% | 13.80% |
| 2024-09-06 | 11.06% | 11.06% |
| 2024-12-31 | 7.07% | 7.07% |
| 2025-06-15（有 EC） | 4.78% | 4.78% |
| 2026-06-01（有 EC） | 19.38% | 19.38% |

没有随标定的单调趋势，**有 EC 的 2026-06-01 反而最高**。所以溢出段占比是轨道/本底
环境驱动的，不是标定驱动。这排除了"增益偏高把真实几 MeV 的事例提前堆进溢出段被丢掉"
这个担心。C 星实测 15.11% 在同一量级。

**顺带一条可以加强的结论**：`PI >= 448` 的占比与 `EVT_TYPE == 2` 的占比
**7 个 epoch 逐位完全相同**。OPEN-QUESTIONS 里原来写的是「`EVT_TYPE == 2` 的事例
PI 正好全落在这一段」，实测可以加强成**两者是同一个集合**，不是包含关系。

## 四、对 CALDB 结论的一条修正

`c2e` 的 epoch 列表里 2025-05 .. 2026-02 是空的（`2025/04/01` 之后直接跳到 `2026/03/01`），
看起来像第二个空缺。**实测不是**：2025-06-15 的峰位 296.72 跟 2026-06-01 的 298.00
是一档的，远离无 EC 的 289 那档。说明 CALDB 的 EC 是**向后顺延**的——`2025/04/01`
那份一直用到 `2026/03`。

**所以真正没有在轨 EC 可用的只有 2022-10 .. 2024-12**，那段前面只有 `1971/01/01` 默认。
而这正好是 A 星唯一落在 WWLLN 覆盖内的那段。
