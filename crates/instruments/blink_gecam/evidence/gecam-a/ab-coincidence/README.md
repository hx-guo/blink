# A/B 双星符合的可行性：共视曝光只有 6 小时量级

2026-09-10 实测。脚本 `/scratchfs2/gecam/guohx/gecam_a/`：`ab_overlap.py`（逐小时 GTI 重叠）、
`ab_separation.py`（星间距离）。逐小时明细 `ab_overlap.json`（647 行）。

A 与 B 的 MET 历元相同（2019-01-01），GTI 可以直接比、不必折回 UTC。
（跟 C 星比才要折，C 的历元是 2021-01-01。）

## 一、GTI 重叠：119.2 小时

| 量 | 值 |
|---|---|
| A 星 2022-2024 曝光 | 370.4 h（647 个小时文件） |
| 同小时 B 星也有文件 | **310 小时（47.9%）**，覆盖 124 天 |
| **A∩B 的 GTI 真重叠** | **119.2 h = 4.97 天** |
| 重叠 / A 总曝光 | **32.2%** |
| 有重叠的小时 | 273 个，单小时重叠中位 1,389 s，最大 3,699 s |

逐月重叠（小时）：2024-02 = 20.4，2024-01 = 18.6，2023-12 = 14.9，2024-06 = 8.4，
2023-06 = 8.2，2024-03 = 7.8，2024-04 = 7.3，2024-09 = 7.0，
2023-08 = 5.5，2023-10 = 4.7，2024-05 = 4.3，2023-05 = 3.3，2023-02 = 2.8，
2023-01 = 2.0，2023-07 = 2.0，2023-09 = 1.6，2022-10 = 0.4；
**2023-04 / 2024-07 / 2024-08 / 2024-12 为 0**。

## 二、但同时刻不等于共视——两星隔着大半个地球

从 posatt 的 `X/Y/Z_WGS84`（米）算星间距离。抽 40 个重叠小时、10 s 一格、
共 8,904 个采样点：

| 量 | 中位 | 5–95% | min | max |
|---|---|---|---|---|
| 星间三维距离 | **8,032 km** | 622–13,763 | 135 | 13,926 |
| **星下点地面距离** | **7,861 km** | 571–18,098 | 123 | 19,970 |

| 星下点距离阈 | 时间占比 |
|---|---|
| < 400 km | 3.7% |
| **< 800 km**（TGF 可见半径常用值） | **5.2%** |
| < 1,600 km | 5.8% |
| < 3,000 km（几何极限，掠射、衰减严重） | 24.8% |

最大值接近对跖（约 20,000 km），说明两星会走到轨道两侧；中位 7,861 km 约 70° 弧。
这符合 GECAM 双星星座为全天覆盖做的设计——**代价是它们绝大多数时间看的不是同一片地球。**

## 三、结论：WWLLN 覆盖内做不了双星符合

119.2 h × 5.2%（< 800 km）= **约 6.2 小时共视曝光**。

按 A 星现在 10.5 候选/s 的率，6.2 小时里 A 会出 23 万个候选，而真 TGF 在这点曝光里
期望是零点几个量级。**先淹死在假候选里，判据做好了也没有统计量。**

### 几点限定，免得这条被过度解读

* **2025–2026 段的账不一样。** A 星 2025+2026 有 3,838 个小时文件，按 57.3% 的 GTI
  折算约 2,190 h 曝光；B 星那段基本满覆盖，所以 A∩B 可能接近 2,190 h，
  × 5.2% ≈ **114 小时共视**，比 WWLLN 段多 18 倍。**但那段没有闪电真值**
  （库止 2024-12-31），只能走单腿——双星符合真要做，得放到 post-2024，
  而且是"两星互为真值"而不是"闪电为真值"。
* **5.2% 是 < 800 km 的口径。** 放宽到 3,000 km 是 24.8%，但那个角度上大气衰减很重、
  TGF 探测效率极低。**这个阈值该定在哪没有 GECAM 自己的数据支撑，属于未决。**
* **定位精度没有评估。** 就算共视，两星的方向重建误差圆（OPEN-QUESTIONS 第 13 条第二档，
  还没做）能不能小到有用，不知道。所以"双星定位"目前连可行性都还没到能评估的地步。

## 四、建议

把"A/B 双星符合"从 A 星的近期路线里拿掉——共视曝光只有 6 小时（WWLLN 段），
不该跟"跑 183 天"并列，那是两个数量级的差别。

保留的话，改成一个**便宜的定向检验**而不是一条产线：等两边都有候选表之后，
按 UTC 对齐，只看那 6.2 小时共视窗内有没有毫秒级同时的对。
**有，就是一个极硬的真 TGF 证据**（假候选是各星独立的粒子，不可能跨星同时）；
**没有，也在预期之内、不构成任何否定。** 成本是一次表连接。
