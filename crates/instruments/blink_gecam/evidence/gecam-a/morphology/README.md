# GECAM-A 的候选形态：候选率是 GECAM-C 的 143 倍，`fa` 救不了它

2026-09-10 实测。基准日 **2024-01-11**（2022-2024 段、无 CPD、无在轨 EC、
q = 29.8 ns），二进制 `e34f560`（含双增益合并），曝光 7,050 s，候选 74,012 个。

逐候选特征表 `feat_20240111.csv.gz`（74,012 行）。
脚本 `/scratchfs2/gecam/guohx/gecam_a/features_a.py`。

## 计数对账

**`n_core == count`：74,012 / 74,012 = 100.00%。**

窗口用最佳格 `[start + delay, start + delay + bin_size_best]`，不是 `[start, stop]`
（`Candidate::merge` 会把 `stop` 拉长，而 `count` 取的是最显著子窗）。

事例口径必须与 Rust 侧一致：**先 `EVT_TYPE == 1 && 54 <= PI < 448` 准入，
再按 (探头, 时戳) 合并双增益重复**。三种口径实测（2024-01-11 h03，8,343 个候选）：

| 口径 | 事例数 | 对账 |
|---|---|---|
| 不合并 | 5,764,179 | **12.83%** |
| **先准入、后合并** | 4,536,061 | **100.00%** |
| 先合并、后准入 | 4,533,835 | 99.90% |

顺序是可分辨的。留哪一条按 `GAIN_TYPE` 最大（低增益）取，与 Rust 侧
`dedupe_gain_pairs` 一致。

## 一、候选率：A / C = 143 倍

| | 曝光 | 候选 | 候选/秒 |
|---|---|---|---|
| **GECAM-A** 2024-01-11 | 7,050 s | 74,012 | **10.498** |
| GECAM-C（17 天合计） | 742,144 s | 54,622 | **0.0736** |

C 星逐日很稳（0.0725–0.0838 /s）。**A / C = 143 倍。**

同一天用旧二进制（未合并双增益）的对照，2026-06-01：

| | 旧 `0df6a5f` | 新 `e34f560` | 变化 |
|---|---|---|---|
| 候选数 | 112,415 | 64,380 | **−42.7%** |
| 候选率 | 17.28 /s | 9.894 /s | −42.7% |
| `signals.json` | 171,972,183 B | 98,311,903 B | −42.8% |

**双增益合并砍掉 42.7%，但 A/C 仍是 143 倍——双增益不是主因。**

25 路对 12 路只能解释 (25/12)² ≈ 4.3 倍；准入后单路计数率两星差不多
（A 748 c/s vs C 780 c/s，**注意不能用过滤前的 2600 c/s 去算**）；
量化步长 A 是 29.8 ns、C 是 14.9/7.45 ns，比 2–4 倍。
**组合数论证只到 9–17 倍，离 143 还差一个量级——没有凑满，列为未解释。**

## 二、`multiplet_frac` 分布：同戳效应比 C 星强一个量级

| 阈 | A 星（2024-01-11，合并口径） | GECAM-C |
|---|---|---|
| `mf == 0` | 512 (0.69%) | 90 (2.66%) |
| `mf ≤ 0.25` | 2,671 (3.61%) | 473 (13.97%) |
| **`mf ≤ 0.3`** | **2,899 (3.92%)** | **528 (15.60%)** |
| `mf ≤ 0.5` | 10,876 (14.69%) | — |
| `mf ≤ 0.8` | 38,018 (51.37%) | — |

`mf` 中位 **0.800**、均值 0.763。`n_core` 中位 9，`n_det_hit` 中位 8，
`max_mult` 中位 4（最大 20）。

**注意 C 星那组数是旧口径（未合并双增益），不能直接比。**
同一份 A 星数据旧口径 `mf ≤ 0.3` 只剩 0.77%，新口径 3.92%，**差 5 倍**，
那个差里混着口径变化。

两条干净的验证：

* `max_mult > n_det_hit` 的候选从旧口径 4.06% 降到 **0.00%**——合并把同探头重复清干净了。
* `det_frac_max > 0.8` 的候选**一个都没有**，中位 0.133。
  **`MAX_DETECTOR_FRACTION = 0.8` 那条判据在 A 星上是空转的。**

**窗长混杂极端**：幸存者（`mf ≤ 0.3`）`bin_us` 中位 **37.10 µs**，
全样本 **0.15 µs**——**247 倍**。任何按 `mf` 分组的比较不做窗长分层就是废的。

## 三、收紧 `fa` 反而更糟——`fa` 不是 A 星可用的把手

| 阈 | 剩余 | 占比 | 其中 `mf ≤ 0.3` | `mf` 中位 | `bin_us` 中位 |
|---|---|---|---|---|---|
| `fa ≤ 1` | 67,506 | 91.21% | 1,397 (**2.07%**) | 0.833 | 0.15 |
| `fa ≤ 1e-5` | 58,258 | 78.71% | 266 (0.46%) | 0.875 | 0.15 |
| **`fa ≤ 7e-7`** | **57,425** | **77.59%** | **220 (0.38%)** | 0.875 | 0.12 |
| `fa ≤ 1e-8` | 56,448 | 76.27% | 138 (**0.24%**) | 0.875 | 0.12 |

**阈收紧 8 个数量级，候选只掉 16%（67,506 → 56,448），而幸存者里低同戳的比例
从 2.07% 掉到 0.24%。**

泊松显著性最高的候选恰恰是挤在 0.12 µs 里的粒子簇——对泊松判据来说显著性拉满。
**`fa` 与 `multiplet_frac` 反相关，更严的假阳性阈救不了 A 星，
反而把样本推向纯粹的同戳污染。**

## 五、器件效应逐级扣除后仍剩 114 倍

按修正后的窗内计数与本底重算泊松 SF，再按 `fa ≤ 20` 的搜索配置阈计数：

| 步骤 | 剩余 | 较上一步 | 较现状 |
|---|---|---|---|
| 现状（已合并精确同时戳） | 74,012 | — | 100.0% |
| 再合并亚死时间对（< 4 µs，见 `../range-ceiling/`） | 69,154 | −6.6% | 93.4% |
| 再切 ch ≥ 368 超量程沉积 | 59,275 | −14.3% | **80.1%** |

**两项器件效应全修完只掉 20%，A/C 仍是 114 倍。
候选率的主体是跨探头的真同戳，也就是带电粒子穿仪器。**

超量程沉积在候选窗里富集 **5.77 倍**（窗内 ch ≥ 368 占比中位 0.25，本底窗 0.047），
94.00% 的候选至少含一个 ch ≥ 368 的事例，`pi_core_max` 中位 373——
**中位候选的最高能事例就落在堆积包里**。但它与 `mf` 只是弱相关
（Pearson r = 0.142，Spearman ρ = 0.094）；亚死时间对与 `mf` 是**负**相关（−0.198）。

**所以超量程沉积主要污染谱（硬度），不是候选率的主因。**

窗长分层后（三层等分位）的单调关系：

| 窗长层 | `hi_frac == 0` | 0–10% | 10–30% | > 30% |
|---|---|---|---|---|
| 0.03–0.12 µs (12,338) | `mf` 1.000 / 0.00% | 1.000 / 0.00% | 0.947 / 0.00% | 1.000 / 0.00% |
| 0.12–0.18 µs (30,263) | 0.867 / 0.00% | 0.917 / 0.00% | 0.875 / 0.00% | 0.875 / 0.00% |
| 0.18–989 µs (31,411) | 0.500 / **25.13%** | 0.667 / 20.87% | 0.625 / 9.19% | 0.667 / **4.45%** |

（每格是 `mf` 中位 / `mf ≤ 0.3` 通过率。）
