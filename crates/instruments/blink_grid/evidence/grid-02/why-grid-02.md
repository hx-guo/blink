# GRID-02：75 天里一个短硬暴都没有，是不是异常？

结论先写：**不异常，而且原因是可量的仪器差异，不是靠统计涨落解释。**

- 只按曝光算，GRID-02 该出 2.94 个短硬暴，实测 0，P = 0.053——这个数**单看统计并不显著**，
  也确实排除不了「GRID-02 与 GRID-03B 同质」。
- 但两颗星的**读出根本不是一种**：GRID-03B 是逐探头独立死时间 4.7684 µs；
  GRID-02 是**四路共用一条读出链**，帧长 28.3718 µs，**帧内所有事例共用触发那一击的时戳**。
- 把 03B 的 29 个真实短硬暴逐个搬到 GRID-02 的读出与真实本底上跑完整条判据链，探测概率只剩
  对照的 **0.181**（自举 16–84%：0.107–0.256）。期望从 2.94 降到 **0.53**，实测 0 的概率
  **0.589**。
- 折扣的一半来自「计数被帧压掉」，另一半来自**共帧把时戳塌成同一个值**，正好撞上
  `MAX_SIMULTANEOUS_FRACTION = 0.35` 这道挡带电粒子的门——真暴发在 GRID-02 上长得像粒子。
- 所以问题的正确问法不是「GRID-02 为什么没有」，而是「以 GRID-02 的读出，75 天本来就
  不该看到」。**要在 GRID-02 上把「与 03B 同质」推到 95% 排除，需要现有低磁纬曝光的 5.7 倍。**

以下每一节都标明实测 / 推断 / 没验成。

---

## 1. 时戳栅格与帧长（实测）

样本：**147 次过境，覆盖全部 75 个观测日**（每日取文件最小与最大各一个，覆盖低率与高率
过境），`EVT_TYPE==1` 的探头内相邻间隔 **2.26e7** 个。工具 `diag/grid04/grid04_deadtime.py`
（统筹指定，未重写），汇总 `diag/grid02/grid02_dt_report.py`。

**时戳栅格 tick = 2⁻²² s = 238.4185791015625 ns，严格。** `dt / tick` 为整数的占比
**1.000000**，最大残差**恰为 0**。用 4.768371582 µs 当 tick 去除只有 5.3% 的间隔是整数，
用 1 µs 只有 0.19%——所以「时戳分辨率 4.77 µs」这个说法不成立，四颗星的 tick 是同一个数
（03B/04/07 我也各测了一天，同样是 2⁻²² s、残差 0）。

**逐探头相邻间隔的硬下限 = 119 tick = 28.3718 µs**，众数在 120 tick = 28.6102 µs：

| tick | µs | 计数 | 占比 |
|---|---|---|---|
| 0–118 | 0–28.13 | 570（散在各格，每格个位数） | 2.5e-5 |
| **119** | **28.3718** | 19043 | 8.4e-4 |
| 120 | 28.6102 | 957535 | 4.25%（峰） |
| 121 | 28.8486 | 471174 | 2.09% |
| 122 | 29.0871 | 685845 | 3.04% |
| 123 | 29.3255 | 46845 | 2.1e-3 |
| ≥124 | ≥29.56 | 每格约 5.5e4 | 每格 2.5e-3（指数尾） |

- tick=0（同一探头同一时戳）只有 **2 个**，即探头内不存在同戳事例。
- 118 及以下的 570 个（2.5e-5）散在 0–118 各格、每格个位数，是时戳毛刺不是物理间隔。
- **四路一致**：EVENTS0/1 首个占比 >0.1% 的格在 120，EVENTS2/3 在 119；峰值四路全在 120；
  四路「低于 120 tick 的占比」分别是 2.77e-5 / 2.53e-5 / 2.45e-5 / 2.57e-5。
- **不随年份或计数率变化**：按月分（2020-11 / 12、2021-01 / 02 / 03）与按单探头率四分位分档
  （59–168 / 168–307 / 307–384 / 384–1374 c/s），下限全落在 119–120 tick。所以「GRID-02 是
  最早一颗、可能是不同代硬件」这条**排除了**，02 与 04/07 属同一档。

跨星对照（各取一天、每天 4 个过境文件）：

| 星 | 帧长 / 死时间 | = tick 数 | 读出结构 | 观测日 | 短硬暴 |
|---|---|---|---|---|---|
| GRID-02 | **28.3718 µs** | 119 | 四路共帧 | 75 | 0 |
| GRID-03B | **4.7684 µs** | 20 | 逐探头独立 | 789 | **29** |
| GRID-04 | 28.6102 µs | 120 | 四路共帧 | 527 | 0 |
| GRID-07 | 28.3718 µs | 119 | 四路共帧 | 195 | 0 |

FITS 的 `DEAD_TIME` 列 GRID-02 恒为 15（µs），与实测的 28.37 µs 不符，是占位值，不能用。
`EVT_TYPE==2` 占比 6.8e-4（03B 一天 1e-4、07 一天 4.6%）。

**没验成**：28.37 µs 这个值的物理来源（成形时间？读出握手？为什么 02/07 是 119 tick 而 04 是
120 tick）归档里看不出来，要问天格团队。

## 2. GRID-02 的四路共用一条读出链（实测，判据是跨探头间隔）

判据（grid04 提出，我用自己的实现独立量了一遍）：**跨探头相邻间隔落在开区间 (0, τ) 的比例**。
四路独立时该比例是连续分布、不为零；四路共帧时只能出现 0 或 ≥ τ。
`diag/grid02/grid02_frame.py`，24 次过境铺满全任务，`EVT_TYPE==1`。

| | GRID-02（τ=119 tick） | GRID-03B（τ=20 tick） |
|---|---|---|
| 过境 | 24（四路合计率 227–1652 c/s，中位 679） | 24（195–34159 c/s，中位 1297） |
| 跨探头相邻间隔 | 2.11e7 | 1.05e8 |
| **= 0 tick** | 1.36% | 1.41% |
| **开区间 (0, τ)** | **102 个 = 4.84e-6** | **3.60e7 个 = 34.45%** |
| ≥ τ | 98.64% | 64.14% |
| 独立模型粗估 | 1.9e-2 | — |

GRID-02 实测比独立模型预期低 **3900 倍**，03B 则是连续铺满。**GRID-02 共帧，03B 不共帧。**

模型自检（`diag/grid02/grid02_framecheck.py`）：把共帧算子施加在 **GRID-02 的真实本底流**上
**近乎恒等**（丢弃占比中位 0.00000、最大 0.00167，时戳被改的占比 0.00000）——真实数据本来就
满足这个帧结构；施加在 **03B 的真实流**上则丢掉 0.14%、改掉 1.1% 的时戳，即 03B 不满足。

**这条为什么要命**：共帧不只是少收计数，它把**帧内所有事例的时戳塌成同一个值**。天格四路
合成一路搜索、没有组间符合，`search.rs` 里挡穿星带电粒子的唯一手段就是
`MAX_SIMULTANEOUS_FRACTION = 0.35`（最显著一格里同戳事例占比超 0.35 就当粒子否决）。
一个真暴发在 GRID-02 上会被读成「每 28.37 µs 一簇、簇内四路同戳」——正是这道门要挡的形态。

## 3. 搜索复刻已逐位验证（实测）

`diag/grid02/grid02_inject.py` 的 `run_search` 复刻了
`blink_algorithms::snapshot_stepping::search_new` 与 `blink_grid::types::chunk::search`
的整条判据链（min_number=8、max_duration=1 ms、本底窗 ±0.5 s、空窗 ±5 ms、fa 门 20/yr、
`Candidate::merge`；否决链 = 读出空洞 9.2 / 速率上限 5000 / 同戳占比 0.35 / 单路占比 0.8）。

在**真实事例流**上重跑：**GRID-02 的 4 个显著候选 4/4、GRID-03B 的 29 个短硬暴 29/29**，
`count` / `mean` / `fa` 三项逐位相同，且没有一个被否决链误砍（`diag/grid02/grid02_selftest.py`）。

复刻时踩到的两个坑，任何回到事例流的脚本都要照做：

1. **cursor 要扫遍整个合并窗 `[start, stop]`**，不能只扫 `start`。最佳子窗从 `start + delay`
   起，只扫 `start` 会漏掉真正的最佳格——只做这一条时是 24/29。
2. **要复刻 `from_epoch` 的小时口径**：`gti` 夹到整点小时内、事例只留小时内，但
   `pass_rate` 的分母仍是**未夹的整次过境时长**。不夹小时的话，03B 有 4 个候选的
   `pass_rate` 会算成 2–6 kc/s（过境跨到辐射带），被 `dead_gap` / `RATE_CEILING` 误否决。

`met()` 的纳秒截断已按统筹给的写法修好；源事例流的最佳格重算计数与 `count` 对账 **29/29 全中**。

## 4. 注入检验：把 03B 的 29 个短硬暴搬到 GRID-02（实测 + 模型）

- **源**：GRID-03B v10 里 `fa ≤ 1e-5` 且最佳格 < 500 µs 的 29 个，取最佳格内的真实逐事例
  （时刻 + 探头号），准入按 `Event::keep` 三条。
- **入射光子**：03B 自己的死时间先反卷回去（非麻痹型，逐探头，τ=4.7684 µs），否则等于把
  03B 已经丢掉的那部分当成「入射就没有」，对 GRID-02 偏乐观。反卷开/关两种都跑，结论一致。
- **本底**：从归档里随机取 48 段 |偶极磁纬| < 25° 的**真实**本底（各 1.3 s，keep 准入后），
  GRID-02 中位 678 c/s、GRID-03B 中位 239 c/s。
- **读出**：先量化到 2⁻²² s 栅格，再按各星实测的模型走——03B 逐探头独立非麻痹型死时间；
  GRID-02 共帧（帧长 119 tick，帧内每路最多 1 个事例，帧内时戳全塌到触发那一击）。相位由
  真实本底自然给出（本底事例会先开帧）。
- **判据**：跑完整条链，判显著用 fa ≤ 1e-5。
- 每个源 × 每种配置 **200 次**随机相位与随机本底段。

| 配置 | 平均探测概率 | 相对对照 | 自举 16–84% |
|---|---|---|---|
| 03B 本底 + 03B 读出（对照） | 0.579 | 1.000 | — |
| 03B 本底 + **02 读出（共帧）** | 0.109 | **0.189** | 0.117–0.261 |
| **02 本底** + 03B 读出 | 0.528 | **0.912** | 0.826–0.996 |
| **02 本底 + 02 读出（共帧）** | 0.104 | **0.181** | 0.108–0.255 |
| 02 本底 + 02 τ 但**假设四路独立** | 0.201 | 0.347 | 0.257–0.438 |

反卷关掉时是 0.590 / 0.113 / 0.512 / 0.108 / 0.197，相对对照 1.000 / 0.192 / 0.867 / 0.183 /
0.334，同一结论。

**读出是主因（×0.19），本底只是次因（×0.91）。** 最后一行是对照实验：同样的 28.37 µs，
若四路各自独立计时，折扣是 0.347；共帧把它再压掉一半到 0.181——**「时戳塌成一个值」这件事
本身，贡献了差不多一半的损失**。

失败原因分解（02 本底 + 02 读出）：**同戳否决 48.4%**、**无候选 21.7%**（计数被帧压到
`min_number = 8` 以下）、读出空洞 13.1%、fa 不够 6.3%。对照四路独立那一行：同戳只占 1.5%、
无候选 33.3%、fa 不够 33.6%——两种模型的失败途径完全不同，但结果都是丢掉。

**7 个闪电认证的 TGF：相对对照 0.251**（自举 0.093–0.415，只有 7 个源，很噪）。逐个：

| 认证 TGF | 计数 | 最佳格 | 共帧模型 p | 四路独立模型 p | 对照 |
|---|---|---|---|---|---|
| 2022-03-13T13:21:57 | 12 | 173.1 µs | 0.390 | 0.005 | 0.590 |
| 2022-03-25T11:46:34 | 8 | 79.6 µs | 0.000 | 0.000 | 0.615 |
| 2022-08-21T01:04:52 | 13 | 41.2 µs | 0.010 | 0.035 | 0.640 |
| 2022-10-04T00:09:56 | 21 | 78.7 µs | 0.005 | 0.550 | 0.670 |
| 2023-07-15T15:54:35 | 9 | 51.0 µs | 0.000 | 0.000 | 0.595 |
| 2023-10-09T12:02:33 | 11 | 94.7 µs | 0.685 | 0.000 | 0.580 |
| 2023-11-03T17:57:56 | 11 | 67.2 µs | 0.000 | 0.000 | 0.645 |

逐个的数在两种模型之间摆得很厉害（最亮的 2022-10-04 在共帧下从 0.550 掉到 0.005，因为
21 个计数塌成几簇同戳后同戳占比越过 0.35），**只有群体量（0.181）是稳的，逐个的不要单独引用**。

机制的解析上界（不依赖任何流量模型）：GRID-02 在时长 T 的窗里最多能记
4·(1 + ⌊T/28.372 µs⌋) 个计数——T = 30 µs 是 8（正好卡在 `min_number`）、50 µs 是 8、
100 µs 是 16、200 µs 是 32；03B 同样的 T 分别是 28 / 44 / 84 / 168。而且共帧下这 8 个计数
必然是「2 簇 × 4 路同戳」，同戳占比 0.5 > 0.35，直接被当粒子否掉。29 个源的最佳格是
30.5–466 µs、计数 8–21，天花板正好压在判据门槛上。

**对照组为什么不是 1.0**：对照 0.579 的意思是「把一个已被 03B 探到的暴挪到随机的低磁纬
03B 本底段上，只有 57.9% 会被重新探到」——这是选择效应（真实的那 29 次各自落在对自己
有利的环境里）加 `dead_gap` 门在低本底率下的边际性（03B 低纬本底中位 239 c/s 时，
9.2/r 对应 39 ms 的临界空段，泊松涨落常常够得着）。所以用**比值**而不是绝对值，
比值里这部分抵消掉。

**没验成**：两颗星的有效面积假定相同（同型 4 路 GAGG+SiPM）。归档里没有面积 / 厚度信息，
这条只能记为假设；若 GRID-02 面积更小，折扣还要更狠。

## 5. 曝光（实测）

`diag/grid02/grid02_exposure.py`（在 grid07 的脚本上只改一行：posatt 采样间隔改为自适应）。
**GRID-02 的 posatt 是 10 s 采样，03B/04/07 是 1 s**——原脚本把 `dtsec` 硬编成 1.0，直接拿去
跑 GRID-02 会把曝光少算 10 倍。

**GRID-02 的轨道跟另外三颗不是一类：倾角约 55°，不是太阳同步。** posatt 的纬度只到
±54.6°（另外三颗是 97° 极轨），所以它**从不进辐射带角**——`dropped_high_rate` 全任务 0 个，
可以印证。

| \|偶极磁纬\| < 15° | 402,050 s = 111.7 h（31.6%） |
| **\|偶极磁纬\| < 25°** | **661,570 s = 183.8 h = 7.66 d（52.0%）** |

03B 的 67.6%）——03B 的过境本来就更集中在低磁纬，**低倾角没有给 GRID-02 带来曝光优势**。

## 7. 四路探头本底谱与能道—能量（实测）

同一批 147 次过境的 `pi_hist`（`EVT_TYPE==1`，未过能量阈）：

- **四路一致性**：ch12 以上四路逐道占比的相对偏差约 0.10（例：ch20 占比 0.01915 / 0.01977 /
  0.01786 / 0.01876）；ch4–11 之间偏差大到 0.3–1.8，是各路阈值曲线不同，不是数据问题。
- **低能端，按四路合计率分层**（`diag/grid02/grid02_frame.py`，与 03B 同口径同脚本）：

  | | GRID-02 | GRID-03B |
  |---|---|---|
  | 安静过境（< 600 c/s） | E_MIN<30 keV 占 **3.24%**，峰 ch12（56.1 keV） | 占 **3.09%**，峰 ch12（55.5 keV） |
  | 中（600–3000 c/s） | 占 3.73%，峰 ch12 | 占 21.86%，峰 ch7（29.3 keV） |
  | 高（> 3000 c/s） | 样本内没有 | 占 1.25%，峰 ch17（86.4 keV） |

  **安静过境下两颗星几乎一样**：30 keV 以下都只占约 3%，谱峰都在 55–56 keV。所以
  30 keV 软阈对两颗星做的是同一件事，**能量阈不是 GRID-02 丢暴的原因**。
  **早先本文写的「GRID-02 硬件低能阈明显高于 03B、03B 的 30 keV 阈砍掉 23.6–44.1%」是错的**，
  那个 03B 数字来自单独一次中等速率过境（21.86% 那一档），不代表 03B；已按分层结果更正。
  03B 的低能端随速率变化很大（安静 3.09% → 中 21.86% → 高 1.25%），做跨星谱比较必须分层。
- **量程上限包**：每路有自己的量程上限，上限之下一个单道堆积峰、之上断崖——
  det0 ch92（1664–1711 keV，占全部事例 1.345%）、det1 ch93（1711–1758 keV，1.298%）、
  det2 ch89（1533–1575 keV，1.073%）、det3 ch86（1410–1450 keV，1.058%）；
  溢出道 ch98 只有 3.1e-5..3.8e-4。`Event::keep` 只把最高道当溢出，所以这些超量程沉积
  以「1.4–1.8 MeV 硬光子」身份进了搜索。03B 上是同样的毛病，上限在 1.28–1.55 MeV。
- **能道→能量**：`io/evt.rs` 逐文件读 `EBOUNDS`、取 `E_MIN[PI-1]` 作 `energy_kev`，
  没有硬编、逐星自动正确；FITS 里除 `EBOUNDS` 外没有别的标定扩展。GRID-02 是
  **98 道、6.657–2011.135 keV**（ch1 = 6.66–10.42、ch7 = 30.21–34.46、ch12 = 56.13–62.01、
  ch20 = 108.89–116.45、ch50 = 455.30–472.10、ch98 = 1958.04–2011.14），
  03B/04/07 是 97 道、5.23–2052.16 keV。**阈值按能量定是对的**：同一道号跨星差几个 keV。

## 8. 否决链账本（实测）

`diag/grid02/grid02_ledger.py`，四星 `*_hours.json` 全量累加。原始候选 = 幸存 + 各
`dropped_*` 之和。

| | GRID-02 | GRID-03B | GRID-04 | GRID-07 |
|---|---|---|---|---|
| 观测日 | 75 | 789 | 527 | 195 |
| 有效搜索秒 | 1,274,120 | 11,236,449 | 9,438,948 | 4,698,442 |
| 原始候选 | 220,489 | 3,458,980 | 3,429,648 | 2,014,915 |
| 原始候选 / 1000 s | **173.05** | 307.84 | 363.35 | 428.85 |
| 幸存候选 | 55 | 2632 | 204 | 122 |

每 1000 个原始候选里各道门砍掉多少：

| 门 | GRID-02 | GRID-03B | GRID-04 | GRID-07 |
|---|---|---|---|---|
| `dropped_dead_gap` | 999.73 | 996.69 | 999.91 | 999.89 |
| `dropped_high_rate` | **0.00** | 0.22 | 0.00 | 0.00 |
| `dropped_simultaneous` | **0.02** | 2.25 | 0.00 | 0.03 |
| `dropped_single_detector` | 0.00 | 0.00 | 0.00 | 0.00 |
| `dropped_no_ephemeris` | 0.00 | 0.07 | 0.03 | 0.03 |
| 幸存 | 0.25 | 0.76 | 0.06 | 0.06 |

读法：

- **GRID-02 的读出空洞否决占比并不比别人高**（999.73‰ 对 03B 996.69‰、04 999.91‰、
  07 999.89‰），按每有效秒算反而**最低**（173 对 307 / 363 / 429）。`search.rs` 注释里
  「GRID-02 与 04 在 5 kc/s 附近就成片出现空洞」是对的，但 GRID-02 因为倾角 55° 从不进
  辐射带，几乎没有机会跑到 5 kc/s——`dropped_high_rate` 全任务 **0 个**。
- **`dropped_simultaneous` 只有 5 个（0.02‰），03B 是 7797 个（2.25‰），每有效秒差 100 倍。**
  这不是「GRID-02 上没有穿星带电粒子」——四路合并流里 dt==0 的事例对占 1.36%，粒子有；
  是四路同戳在共帧读出下只有 4 个计数，压在 708 c/s 的本底上够不着 fa ≤ 20/yr 的候选门，
  根本没成为候选，也就轮不到这道门去砍。**同戳门在全量搜索里几乎没开火，却在注入检验里
  否掉了 48.4% 的真暴发**——因为真暴发的计数比穿星粒子多，够得着候选门，然后才撞上这道门。
- GTI 内事例（未过 keep）平均率：GRID-02 1078 c/s、03B 2188、04 1586、07 1045。
  03B 高是因为极轨过辐射带，不是它本底更脏。

## 9. 终算

以 |偶极磁纬| < 25° 的有位置曝光为分母（GRID-02 661,570 s，GRID-03B 6,532,713 s，
比 0.1013），GRID-03B 的 29 个短硬暴 / 7 个闪电认证 TGF：

| | 只按曝光 | P(0) | 仪器折扣 | 折扣后期望 | P(0) |
|---|---|---|---|---|---|
| 29 个短硬暴 | 2.94 | 0.053 | **×0.181** | **0.53** | **0.589** |
| 7 个认证 TGF | 0.71 | 0.492 | ×0.251 | 0.18 | 0.837 |

**「以 75 天的曝光，能不能排除 GRID-02 和 03B 同质」——不能。**
实测 0 个，95% 置信上限是真期望 ≤ 3.00，即 GRID-02 的单位低磁纬曝光 TGF 率
**≤ 5.7 倍 03B**（折扣后口径）。要把同质推到 95% 排除，需要现有低磁纬曝光的 5.7 倍，
即再要约 400 个观测日——GRID-02 的事例产品只到 2021-03-08，拿不到了。

但**不需要**排除同质来解释「GRID-02 一个短硬暴都没有」：以共帧读出，75 天本来期望就只有
0.53 个，实测 0 完全正常。这一条不吃统计量，它是仪器属性。

同一个折扣直接适用于 GRID-04（帧长 28.6102 µs）与 GRID-07（28.3718 µs）——它们的
「期望 19.4、概率 4e-9」也要先乘这个折扣再谈异常，那才是四星对照该有的分母。
